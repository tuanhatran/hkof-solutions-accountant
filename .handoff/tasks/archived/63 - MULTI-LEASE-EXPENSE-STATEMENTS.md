## Goal
Multi-lease expense statements: the expense page gets a lease selector next to the company (only that company's leases; one auto-selected, several requiring an explicit choice; locked when `options.leaseId` is injected), and the selected lease drives expense items, pro-rata, calculation, preview, generation, the active banner, the rent receipt picker and the saved draft. Statements become versioned/archived/active per company+month+lease, so generating lease A never archives lease B. Company settings keep « Bail actif » but the expense page no longer reads it. Out of scope: rent receipt generation, templates, money rules (`CalculationService` untouched).

## Constraints
Contract: written in YAML first, then backend, then generated types; report exact paths/fields. Money: `CalculationService` only, backend total is the reference. UI French + EN i18n, no `any`, classes and component CSS < 300 lines. Logical deletion only; builder commits once (explicit paths, never the staged `.handoff/tasks/62...` file), nobody pushes.
Lease scope: resolve the effective lease with `leases.resolveExpenseLease(companyId, request.leaseId())`; use its id for version lookup, archive, active query and file names. Legacy statements with `lease_id IS NULL` are their own scope. Migration V17: add `document_draft.lease_id`; replace `uq_expense_statement_company_month_version` and `ux_expense_statement_active`, and `ux_document_draft_statement_scope`, with `COALESCE(lease_id, 0)` variants (unique per company+month+lease+version and one ACTIVE per company+month+lease; one statement draft per month+company+lease). Keep the spec number `NF-YYYY-MM` unchanged; include the lease in stored PDF names (`note_frais_<month>_l<leaseId|0>_v<version>.pdf`, `_complet`) so one lease never overwrites another's file. Scope the ZIP rent annex by the statement's lease parties (company lease: landlordId + tenantCompanyId; person scope: landlordId + tenantId) and the `/draft` rent receipt likewise.
Frontend: leases are the company leases (`lease.companyId === activeCompanyId`); no lease => no expense item, receipt, draft or generation; several leases and none chosen => French prompt, Save Draft and Generate disabled. Draft scope becomes company+month+lease (`draftScopeKey`, store, query key, save body); the scoped company-lease modal passes its locked lease.
